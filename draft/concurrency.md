# Конкурентность vs параллелизм

> Конкурентность — это об одновременной работе с множеством задач.
> Параллелизм — это об одновременном выполнении множества задач.
>
> — Роб Пайк (Rob Pike)

## Отличия

**Конкурентность** — это про структуру программы: её ветви устроены так, что
при необходимости их можно запустить параллельно. На одном ядре такие ветви
выполняются по очереди, с очень быстрыми переключениями между ними.

**Параллелизм** — это про одновременное выполнение кода на разных ядрах:
каждое ядро выполняет свою ветвь программы.

**Конкурентный параллелизм** — сочетание двух подходов: конкурентные задачи
распределяются по нескольким ядрам, и на каждом ядре ветви по-прежнему
выполняются конкурентно.

Конкурентность выигрывает на большом количестве неблокирующих операций
ввода-вывода (`I/O-bound`), параллелизм — на больших объёмах вычислений
(`CPU-bound`).

В любой непонятной ситуации пишите бенчмарк!

## Конкурентная запись в map

В `Go` тип `map` не потокобезопасен. Например, программа с кодом ниже
завершится фатальной ошибкой `fatal error: concurrent map writes`:

```go
package main

import "sync"

type Storage struct {
    data map[int]int
}

func New() *Storage {
    return &Storage{data: make(map[int]int)}
}

func (s *Storage) Add(id, count int) {
    s.data[id] = count
}

func main() {
    s := New()

    var wg sync.WaitGroup

    for i := range 100 {
        wg.Add(1)

        go func() {
            defer wg.Done()

            s.Add(i, 1)
        }()
    }

    wg.Wait()
}
```
